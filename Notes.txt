Media Queries:
--------------
Help create a responsive website
@media(width: 600px){
	div{
		background-color: red;
	}
}
@media(min-width: 600px){
	div{
		background-color: red;
	}
}
@media(min-width: 200px) and (min-width: 300px){
	div{
		background-color: red;
	}
}
Position:
=========
->static => default Position.
->relative => element is relative to itself.
->absolute => positioned relative to its closed positioned ancestor. 
->fixed => positioned relative to browser.
->sticky => positioned based on user's scroll position.

--------
